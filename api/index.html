Documentación de API

Base URL

http://localhost:5000

Endpoints

Descripción: Endpoint raíz para verificar que la API está en funcionamiento. Parámetros: Ninguno Respuesta:

{

}

Módulo Mecánica

GET /api/mecanica/fuerza

Descripción: Calcula la fuerza utilizando la segunda ley de Newton. Parámetros:

  • masa (float)
  • aceleracion (float)

Respuesta:

{
  "fuerza": 20
}

Ejemplo:

curl "http://localhost:5000/api/mecanica/fuerza?masa=10&aceleracion=2"

Ejemplo en Python:

import requests

response = requests.get("http://localhost:5000/api/mecanica/fuerza", params={"masa": 10, "aceleracion": 2})
# retorna: {"fuerza": 20}
